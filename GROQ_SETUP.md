# Groq API Setup Guide

## ✅ Step 1: Get your free Groq API key
1. Go to https://console.groq.com
2. Sign up and create an API key
3. Copy the key starting with `gsk_`

## ✅ Step 2: Install dependency
```bash
pip install groq
```

## ✅ Step 3: Run the dashboard
```bash
python run_all.py
```

## ✅ Step 4: Use Groq in Command Center
1. Open the dashboard
2. Login as admin or user
3. In the sidebar, select **AI Provider = Groq**
4. Paste your Groq API key
5. Use **Analyze System with AI** or **Generate Groq Runbook**

## Features enabled
- Fast AI incident analysis
- Interactive SRE chat
- Runbook generation for predicted incidents
